# Local engineering platform stack

This project now includes local orchestration for:
- PostgreSQL
- MongoDB
- Neo4j
- Redis
- Backend API
- AI Worker

Run with:

```bash
docker compose up --build
```

Access points:
- API: http://localhost:8000
- PostgreSQL: localhost:5432
- MongoDB: localhost:27017
- Neo4j Browser: http://localhost:7474
- Redis: localhost:6379
